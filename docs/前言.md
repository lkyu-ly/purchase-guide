# <p align="center">前言</p>

得益于 AI 工具的飞速发展，购机指南在 AI 时代迎来了涅槃重生。尽管本人已从母校毕业，精力不复往日，难以再像从前那样逐篇推敲参数、反复比对机型、数易其稿，但仍有不少新入学的同学非常关注购机指南，这份牵挂便有了延续的理由。

电脑110社团自 2007 年创立，至 2022 年停止招新，在无数仁人志士的不懈努力下，创造过属于它的鼎盛时期，也因其志愿社团的局限性不可避免地走向了衰落。这其中有人为的因素，但也与大环境变化密切相关。我在社团群中工作了两年，虽也与社团遗老付诸相当努力，然而我心难安。对建设社团这个需要几代人努力的浩大工程而言，我的努力毕竟时者甚短，功效甚微。我们曾尝试过许多方法，试图复兴社团，但正如所有走向衰败的王朝一样，这只不过是强行续着一口气罢了；而随着人员的变动，这最后一口气也即将结束它的使命。后来的故事会怎么样，我们并不知晓，这得靠之后的学生继续书写。电脑110社团与购机指南的故事并未停更，或许在不久的未来，它会以另一本书的形式重新连载。明人张岱自撰墓志铭有言：“学书不成，学剑不成，学节义不成，学文章不成，学仙学佛，学农学圃俱不成。”我于社团建设，亦大抵如是，但总还留下些摸索的痕迹，供后来者参考——若留下探索，后人总结；若留下经验，后人咀嚼；若留下教训，后人借鉴；若留下失误，后人避免。

我们也可以自豪地说，这三年的购机指南无疑是成功的，其可传播性与可读性在我们的努力下，已经做到了全网文字类指南的一流水平，在全国高校中更是“遥遥领先”。正如劳板所说，“与其说我们编写了一份指南，倒不如说我们总结了对笔记本电脑的方法论”，其价值不止体现在简单的机型推荐，相信大家在细读之后定能有所收获。

今年指南的更新方式会有些变化：前言与新更新机型的主体内容，将由 DeepSeek 大模型生成；其中总结评价部分，则依据前几年购机指南的内容蒸馏而成的 skill，依托 Claude Code 接入的 DeepSeek 大模型生成。今年的购机指南将采用完整版模式进行编写，但仍会保留去年饱受好评的优缺点对比表，以便读者迅速定位自己的需求。对于购机指南的所有内容，我们也会进行全面更新；后续计划于 2027 年更新一个大版本，并尽量在每个学期开始时与 618、双11 前进行小版本的修改。

2025 年的机圈，相对来说是稳步前进的。国补落地在一定程度上促进了厂商的创新热情，同时在机械革命等三线厂家的刺激下，各家厂商都交上了一份不错的答卷。但 2026 年的市场，无疑是给厂家与消费者泼了一盆冷水。首先是国补比例减少，这意味着消费者所承担的成本有所上升；其次，一整年的内存与硬盘价格拉升，叠加最近显卡价格的上涨，使厂商的配件成本大幅攀升——硬盘成本相比去年翻了三倍，内存翻了四倍，显卡翻了一倍，最终的成本仍由消费者承担。今年笔记本价格已经上涨接近一倍，我们几乎可以预见到，曾经的 32G+1T 配置将只会出现在高端机上，中低端价位的笔记本将回归 16G+512G 甚至 12G+512G 的经典配置；目前主流游戏本的显卡配置已经是 5050，不少厂家甚至推出了 3050 的库存机器。今年和明年都是笔记本电脑的寒冬年，CPU 与 GPU 方面并没有较大的更新，AMD与Intel的新CPU 与60 系显卡的发布不知道等到猴年马月；内存和硬盘的价格在明年仍有上涨的可能。当然，各家厂商的新模具相比去年得到了一定的更新，但价格方面也定会有所取舍。如果不是刚需购买电脑，并且手中尚有机器可以使用，我们不推荐购买新机；今年我们也会推出同配置价位能够组装的台式机对比，方便读者根据自身需求作出选择。
